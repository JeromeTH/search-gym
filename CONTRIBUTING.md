# Contributing to CORVAX

We welcome issue reports, ideas, and pull requests!

By submitting a contribution, you agree that:

- Your contribution will be licensed under the same AGPLv3 terms.
- You grant the project maintainer the right to modify, redistribute, and relicense your code under the AGPLv3.
- You retain copyright over your own work.

All contributions are reviewed before inclusion.

## Contribution Process

1. Fork the repo and create a branch
2. Submit a PR to the `dev` branch
3. Describe your changes clearly

Large features or changes should be discussed via GitHub Issues first.
